The icons package exports a large generated React icon set. The catalog below is
a clean, searchable showcase: filter by variant, select the icons you need, and
download them directly as SVG files.
</Description>

## Exports

- Hundreds of generated icon components, typically in Filled and Regular variants
- Sized icon variants for supported sizes

## Installation

```bash
pnpm add @axiscommunications/fluent-icons
```

## Using the catalog

- **Search** by name to find an icon quickly.
- **Filter** by `Regular` or `Filled` to narrow the variant.
- **Select** one or more cards, then use **Download selected** to save them all
  as SVG — or use the download button on a single card.

## Guidance

- Use the searchable catalog to discover icon names before implementation.
- Keep icon usage semantically consistent across products.
- Prefer a single icon family or weight within the same interaction cluster.
