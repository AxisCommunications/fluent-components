<Subtitle>Theme-aware illustration library with light and dark variants.</Subtitle>
<Description>
The illustrations package provides generated React illustrations plus helpers for
bundling dark and light variants together. The catalog below is a clean,
searchable showcase: filter by variant, select the illustrations you need, and
download them directly as SVG files.
</Description>

## Exports

- Generated illustration components in Dark and Light variants
- bundleIllustration
- bundleIllustrationSmart

## Installation

```bash
pnpm add @axiscommunications/fluent-illustrations
```

## Using the catalog

- **Search** by name to find an illustration quickly.
- **Filter** by `Light` or `Dark` to narrow the variant.
- **Select** one or more cards, then use **Download selected** to save them all
  as SVG — or use the download button on a single card.

<Canvas of={IllustrationStories.Catalog} />

## Guidance

- Use bundled helpers when the current theme should automatically drive the illustration variant.
- Choose illustrations that reinforce empty, onboarding, and success states without overwhelming nearby content.
- Keep illustration containers large enough to preserve readability.
